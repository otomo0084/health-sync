health-sync

health-sync is a personal tool. It reads the developer's own sleep and health data from the Google Health API once a day and saves it on the developer's own computer, so that the developer can analyze it together with the developer's own calendar.

health-sync は個人用のツールです。開発者本人の睡眠・健康データを Google Health API から1日1回読み取り、開発者本人のコンピューターに保存します。開発者本人のカレンダーと合わせて分析するために使います。

  • Users: the developer only / 利用者は開発者本人のみ
  • Access: read-only (sleep, health metrics and measurements) / 読み取り専用（睡眠、健康指標と測定値）
