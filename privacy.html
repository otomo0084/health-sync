Privacy Policy / プライバシーポリシー

Last updated: 2026-10-22

Data accessed / 取得するデータ

health-sync reads, with read-only access, the developer's own sleep data and health metrics and measurements (such as heart rate, heart rate variability, resting heart rate, skin temperature, blood oxygen and respiratory rate) from the Google Health API.

health-sync は、開発者本人の睡眠データと健康指標・測定値（心拍、心拍変動、安静時心拍、皮膚温、血中酸素、呼吸数など）を、Google Health API から読み取り専用で取得します。

Use / 利用目的

The data is used only for the developer's personal analysis. It is not used for advertising, it is not sold, and it is not shared with any third party.

データは開発者本人の個人的な分析にのみ使います。広告には使わず、販売せず、第三者に提供しません。

Storage / 保存

The data and the access tokens are stored only on the developer's own computer. The tool has no server and does not collect data from any other user.

データとアクセストークンは開発者本人のコンピューターにのみ保存します。サーバーは持たず、他の利用者のデータは収集しません。

Deletion / 削除

Access can be revoked at any time from the Google Account permissions page (https://myaccount.google.com/permissions). Stored data can be deleted by removing the local files.

アクセス権は Google アカウントの権限ページ（https://myaccount.google.com/permissions）からいつでも取り消せます。保存したデータはローカルのファイルを消すことで削除できます。

Google API Services User Data Policy

health-sync's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
